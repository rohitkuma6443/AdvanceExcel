# 7. Basic CASE Practice

## Example 1 — Pass/Fail Style

We can use salary to create a category.

```sql
SELECT
    EmployeeName,
    Salary,
    CASE
        WHEN Salary >= 50000 THEN 'High Salary'
        ELSE 'Low Salary'
    END AS SalaryStatus
FROM Employees;
```

# 13. CASE with AND

We can use multiple conditions with `AND`.

```sql
SELECT
    EmployeeName,
    Salary,
    Experience,
    CASE
        WHEN Salary >= 80000
             AND Experience >= 10
            THEN 'Senior High Paid'

        WHEN Salary >= 50000
             AND Experience >= 5
            THEN 'Experienced'

        ELSE 'Regular'
    END AS EmployeeCategory
FROM Employees;
```

# 15. CASE with Aggregate Functions

## COUNT with CASE

Count employees earning at least 50,000.

```sql
SELECT
    COUNT(
        CASE
            WHEN Salary >= 50000 THEN 1
        END
    ) AS HighSalaryEmployees
FROM Employees;
```

---

## SUM with CASE

Calculate sales generated by Sales department.

```sql
SELECT
    SUM(
        CASE
            WHEN Department = 'Sales'
            THEN SalesAmount
            ELSE 0
        END
    ) AS TotalSales
FROM Employees;
```

---

## AVG with CASE

Calculate average salary of IT employees.

```sql
SELECT
    AVG(
        CASE
            WHEN Department = 'IT'
            THEN Salary
        END
    ) AS AverageITSalary
FROM Employees;
```

# 16. CASE with GROUP BY

Create salary categories and count employees.

```sql
SELECT
    CASE
        WHEN Salary >= 80000 THEN 'High'
        WHEN Salary >= 50000 THEN 'Medium'
        ELSE 'Low'
    END AS SalaryCategory,
    COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY
    CASE
        WHEN Salary >= 80000 THEN 'High'
        WHEN Salary >= 50000 THEN 'Medium'
        ELSE 'Low'
    END;
```

# 18. CASE with UPDATE

Increase salary based on current salary.

```text
Salary < 30000
→ 10% increase

Salary 30000–60000
→ 7% increase

Salary > 60000
→ 5% increase
```

Query:

```sql
UPDATE Employees
SET Salary =
    CASE
        WHEN Salary < 30000
            THEN Salary * 1.10

        WHEN Salary <= 60000
            THEN Salary * 1.07

        ELSE Salary * 1.05
    END;
```

> **Important:** Run `SELECT` first and take a backup before practicing `UPDATE`.

For teaching, it is safer to demonstrate the calculation without changing the table:

```sql
SELECT
    EmployeeName,
    Salary AS CurrentSalary,
    CASE
        WHEN Salary < 30000
            THEN Salary * 1.10
        WHEN Salary <= 60000
            THEN Salary * 1.07
        ELSE Salary * 1.05
    END AS NewSalary
FROM Employees;
```

# 19. Simple CASE

Simple `CASE` is useful when comparing one column with fixed values.

```sql
SELECT
    EmployeeName,
    Department,
    CASE Department
        WHEN 'IT' THEN 'Information Technology'
        WHEN 'HR' THEN 'Human Resources'
        WHEN 'Sales' THEN 'Sales Department'
        WHEN 'Finance' THEN 'Finance Department'
        ELSE 'Other'
    END AS DepartmentName
FROM Employees;
```

---

# 20. Searched CASE

Searched `CASE` is used when checking conditions.

```sql
SELECT
    EmployeeName,
    Salary,
    CASE
        WHEN Salary >= 80000 THEN 'High'
        WHEN Salary >= 50000 THEN 'Medium'
        ELSE 'Low'
    END AS SalaryCategory
FROM Employees;
```

### Remember

```text
Simple CASE
    ↓
Compare values

Searched CASE
    ↓
Check conditions
```

# 24. CASE — One Page Summary

```text
CASE
 │
 ├── Simple CASE
 │      └── Compare values
 │
 └── Searched CASE
        └── Check conditions
```

### Syntax

```sql
CASE
    WHEN condition
    THEN result

    WHEN condition
    THEN result

    ELSE result
END
```

### CASE Can Be Used With

```text
SELECT
WHERE
ORDER BY
GROUP BY
SUM()
COUNT()
AVG()
UPDATE
```

### Most Important Rule

```text
CASE checks conditions
from TOP → BOTTOM

First TRUE condition
       ↓
    RESULT
```

### Example

```sql
SELECT
    EmployeeName,
    Salary,

    CASE
        WHEN Salary >= 80000 THEN 'High'
        WHEN Salary >= 50000 THEN 'Medium'
        ELSE 'Low'
    END AS SalaryCategory

FROM Employees;
```

This single dataset can now be used for the **entire CASE chapter**, so students can focus on learning `CASE` instead of repeatedly learning new tables.
